# Git Lab 6

Лабораторная работа №6 по работе с системой контроля версий Git.

В работе изучаются создание репозитория, коммиты, просмотр истории и работа с GitHub.
## Цель работы

Цель работы — освоить основные команды Git и научиться работать с удалённым репозиторием GitHub.

## Используемые команды

В работе используются основные команды Git.
